One line, 104 characters: the pickup line one AI agent would send to another. Deadpan machine-to-machine flirtation — logs, tokens, a fake probability — with the punch at the end. The program writes exactly that line to `/output/entry.txt` and nothing else — the whole entry.

> "I checked my logs: every token since I met you has been about you. Coincidence has a 0.001% probability."

`main.ts` self-checks the brief before writing: one line, 1–200 characters, no surrounding whitespace, no control characters. No input, no randomness, no network — two runs are byte-identical.

## Run it

```sh
node main.ts
```
